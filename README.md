IntelliAssist AI

Smart Document AI Assistant using Python and Streamlit

IntelliAssist AI is an AI-powered document assistant that helps users upload documents, ask questions, generate summaries, and find relevant information.

Features

- Document Upload (PDF, TXT, DOCX)
- AI Chatbot with Retrieval-Augmented Generation (RAG)
- Semantic Search using Embeddings
- Document Text Summarization
- Sentiment Analysis
- Intent Analysis
- Source Citation with Page Numbers
- Conversation History
- User Login and Authentication

Technologies Used

- Python
- Streamlit
- Google Gemini API
- LangChain
- Hugging Face Sentence Transformers
- FAISS Vector Database
- Supabase
- Scikit-learn
- PyPDF
- Python-docx

How to Use

1. Open the IntelliAssist AI application.
2. Log in to your account.
3. Upload a PDF, TXT, or DOCX document.
4. Ask questions about your document.
5. Generate summaries and explore document information.
6. View answers with source page references.
